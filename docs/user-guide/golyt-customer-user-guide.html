Before you start

  • Open the GoLyt website in a browser (local default: http://localhost:5173).
  • You do not need a mobile app for the pilot — use this site and your private track link.
  • Switch language with EN / SW in the top navigation.
  • Officers use a separate ops app; operations lead uses the admin console. This guide is for travellers only.

2. How it works

Four stepsNo GPS

How it works explains sealed custody — status events, not live maps.

  1. Book — choose a service online or register at KIA intake with an officer.
  2. Secure — QR label, photos, and seals create a sealed custody record.
  3. Transfer — manifest handover moves bags toward Zanzibar storage.
  4. Collect — you get a ready notice, then verified release at the pickup desk.
Tracking is status-based. Share your private track link only with people who should see bag status.

Core journey

4. Book a service

QuoteTravel detailsAccount

Book is where travellers create a quotation and convert it into a booking.

  1. Select a service and number of bags, then choose Get quote.
  2. Review the quote amount and expiry.
  3. Sign in under Account if you have not already — converting a quote requires a customer account.
  4. Enter travel details (arrival flight, KIA date, Zanzibar date/flight, hotel, notes).
  5. Choose Create booking. Payment initiation may appear as a later-phase checkout step.
Guests can request a quote without signing in. Creating the booking needs a registered customer account.

5. Track luggage

Private tokenTimelinePickup

Track luggage shows sealed-custody status using the bag code and private token from your GoLyt message or officer.

  • Enter Bag code and Tracking token, then Show status.
  • Review the custody timeline (received, sealed, airline handover, Zanzibar storage, ready, released).
  • Pickup name, place, hours, and phone appear when available.
  • Open printable track page opens a shareable/print-friendly track view in a new tab.

Your profile

6. Customer account

Register / Sign inBookingsSupport

Account is the traveller portal for identity, bookings, and support tickets.

  • Register with full name, phone, nationality, passport, email, and password.
  • Sign in to see your profile, open bookings, and receipt summary details.
  • Cancel an OPEN booking when needed.
  • Open a support ticket from Account (signed-in messages are tracked against your profile).
Customer accounts are separate from officer and admin staff accounts. Use the website Account page — not the ops console.

7. Contact, FAQs & tips

DeskFAQs

Contact lists desk details and a message form. FAQs answers common pilot questions.

  • No traveller mobile app is required for the pilot.
  • Bags move KIA intake → sealed custody → airline handover → Zanzibar storage → collection.
  • There is no live GPS — tracking is custody status only.
  • Collection requires the named traveller with ID verification at the pickup desk.

Figure 9 — FAQs for the pilot corridor.

Quick tips

  • Keep your track token private.
  • Bring matching ID to the Zanzibar desk.
  • Confirm pickup hours on your track link.
  • Use EN/SW anytime from the header.
